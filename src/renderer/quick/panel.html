Metadata & Scrobble Rules

Control how SiriusXM broadcast metadata is cleaned and verified before scrobbling.

Scrobble Threshold

SiriusXM never publishes a track duration. VegaAM measures the songs it hears end‑to‑end on the channel and requires half of a song before it is submitted. A song that ends while it is still shorter than the threshold is submitted as well, so short songs are never lost.

Threshold in force 90s · adaptive

Scrobble-Muted Channels

Tracks played on muted channels (e.g. talk, news, comedy, or ambient) will not be scrobbled.

Single-Artist Channel Mappings

Map dedicated artist channels (e.g. E Street Radio → Bruce Springsteen) for broadcasts that omit the artist field. The mapping is also used when the player publishes a decorated channel name such as Bruce Springsteen / E Street Radio.

Artist Aliases

Rename an artist exactly as the player publishes it, e.g. Bruce Springsteen & The E Street Band → Bruce Springsteen. The corrected name is what gets scrobbled, so your profile stays clean.

Manual Track Corrections

Override mislabelled SiriusXM broadcast strings whenever they air again. Use Fix on a history entry (or the current track in Activity) to fill the fields automatically - typing the broadcast strings by hand is not required.

Leave the broadcast artist empty to apply the correction to that song for every artist. The correction matches the broadcast strings as well as the names shown in the interface.

Surface Theme Technical & Contractual Information

VegaAM surface themes are an optional, local appearance customization (disabled by default until you select a theme).

  • How it works: Uses Electron's webContents.insertCSS(css, { cssOrigin: 'user' }) and removeInsertedCSS(key) to remap SiriusXM's 1,288 --color-* design tokens.
  • What is never touched: Zero DOM scripts or navigation elements are injected into the SiriusXM page. Login, account, billing, and checkout routes automatically pause custom themes. Audio streams, Widevine DRM, and network requests are completely unmodified.
  • Instant reset: Click Reset to Official in the header at any time to immediately remove all injected CSS without reloading or interrupting playback.

Windows V-Star Icon Identity & Legacy Cleanup

AppUserModelID: app.vegaam.desktop — the taskbar icon is repaired automatically at start-up. A shortcut that claims this identity while pointing at an Electron binary is removed, because Windows would otherwise draw the stock nucleus instead of the V-star.
